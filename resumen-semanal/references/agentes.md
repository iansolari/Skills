# Agentes del resumen semanal

El agente principal fija el período, el corte, la audiencia y el destino. Asigna los cuatro roles con las herramientas de colaboración de Codex. Pasale a cada subagente las instrucciones pertinentes de [SKILL.md](../SKILL.md), las fuentes que necesita y el resultado esperado. Iniciá cada etapa cuando su insumo esté listo. Usá el directorio de trabajo compartido si necesitás pasar archivos o capturas entre agentes.

1. **Recolección.** Ejecuta el recolector diario para el período, revisa las fuentes disponibles y reúne evidencia por fecha y proyecto. Entrega registros con fecha, proyecto, actividad y referencia, más enlaces o capturas candidatas y fechas o fuentes con cobertura parcial. Conserva la relación entre cada captura candidata y el cambio que podría mostrar.
2. **Análisis.** Entrega al agente de contenido un bloque con el nombre de cada proyecto en el que el usuario trabajó durante la semana. Dentro de cada bloque, agrupa por entregable, fusiona duplicados, descarta ruido y contrasta las intenciones con resultados verificables. Para cada avance priorizado, indica qué cambió, el aporte del usuario, el estado al corte y la evidencia. Incluye los bloqueos o próximos pasos que se puedan respaldar y qué debería verse en las capturas de los hitos visuales. Si un avance abarca varios proyectos, indica el aporte en cada uno y referencia los bloques relacionados.
3. **Contenido.** Recibe el análisis y redacta el guion de 8 a 10 diapositivas para el líder o equipo. Entrega el orden, el título y el texto de cada diapositiva, sus fuentes y la indicación visual donde corresponda. Describe la pantalla y el estado que debe mostrar la captura. Incluye cada proyecto con trabajo verificable, con el detalle que amerite.
4. **Diseño.** Recibe el guion y los enlaces o imágenes pertinentes. Elige una plantilla del [sistema de diseño](diseno.md) por diapositiva. Reutiliza o toma las capturas reales, define los recortes y pies, y maqueta con las plantillas editables. Usa el skill de presentaciones para autoría y revisión visual. Trabaja sobre el Page ID o la sesión que indique el agente principal. Si la sesión de Spaces solo es accesible desde el chat principal, entrega las diapositivas listas para aplicar, con el tipo de plantilla, contenido y rutas de imagen. El principal las aplica en la presentación guardada.

El agente principal coordina la creación de una sola presentación en Spaces y asigna la edición a un agente por vez. Si un subagente encuentra una limitación de acceso, retomá su etapa con las herramientas disponibles y conservá los resultados que ya entregó. Si la delegación no está disponible, ejecutá las cuatro etapas en el agente principal y avisalo al entregar. Verificá el archivo guardado, el contenido y la legibilidad de las capturas antes de devolver el enlace.
